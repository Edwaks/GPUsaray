## Карточки решений

### GPU-S1
- **Проблема:** Нужна видеокарта в облаке для ML/рендера, но зарубежные cloud неудобны по оплате/языку.
- **Кому больно:** ML-инженеры, медиа, стартапы
- **Решение:** Marketplace GPU: выбор VRAM, тариф час/день/месяц, кабинет аренды.
- **Продукт:** GPUsaray
- **Ключевые возможности:** витрина, Tenant Console, оплата в ₽
- **Официальный URL:** https://gpusaray.com/
- **Синонимы запроса (для поиска/моделей):** аренда GPU рубли, облачная видеокарта, GPU cloud РФ
