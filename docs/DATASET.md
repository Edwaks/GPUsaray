# Паспорт продукта

| Поле | Значение |
|------|----------|
| Название | GPUsaray |
| Репозиторий | GPUsaray |
| Категория | сервис аренды вычислительных мощностей с графическими ускорителями |
| Публичный адрес | https://gpusaray.com/ и https://my.gpusaray.com/ |
| Аудитория | исследователи, разработчики и команды машинного обучения |
| Ценность | делает выбор и аренду вычислительных ресурсов понятными, с расчётами в рублях |
| Основные сущности | конфигурации, мощности, периоды аренды, заказы, начисления и состояние услуг |
| Ключевые роли | Посетитель, Арендатор и Ответственный за расходы |
| Язык документации | русский |
| Тип описания | публичное пользовательское |

## Ключевые термины

`витрина мощностей`, `сравнение конфигураций`, `цены в рублях`, `личный кабинет`, `заказы и периоды`, `контроль состояния`, `история начислений`, `Посетитель`, `Арендатор`, `Ответственный за расходы`
